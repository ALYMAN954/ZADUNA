# زادُنا | ZADUNA

التطبيق العائلي لحفظ القرآن الكريم والتسميع والمراجعة والمكافآت.

## الملفات
- `index.html` — التطبيق كاملاً في ملف واحد (الخطوط والشعار وبيانات المصحف بداخله).
- `sw.js` — يجعل التطبيق يعمل بلا إنترنت بعد أول فتح.
- `manifest.webmanifest` و `icon-*.png` — أيقونة التطبيق عند إضافته للشاشة الرئيسية.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً (مثلاً `zaduna`). يمكن أن يكون عاماً أو خاصاً حسب خطتك في GitHub.
2. ارفع كل محتويات هذا المجلد كما هي (كلها في مستوى واحد بلا مجلدات) إلى الفرع `main`.
3. Settings ← Pages ← Source: `Deploy from a branch` ← `main` / `root` ← Save.
4. بعد دقيقة يظهر الرابط: `https://<اسمك>.github.io/zaduna/`

## على الجوال
- **آيفون (Safari):** افتح الرابط ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **أندرويد (Chrome):** افتح الرابط ← القائمة ⋮ ← «تثبيت التطبيق».

## أول تشغيل
1. على جوال عبد الله: اختر «عبد الله» وعيّن كلمة السر.
2. من زر المزامنة ⇄ اضغط «إرسال» ← واتساب ← إيمان.
3. على جوال إيمان: افتح الرابط ← «لديّ ملف من الجوال الآخر» واختر الملف، أو أعدّي حسابك ثم استلمي الملف.
   بعدها تستطيع إيمان تعيين كلمة سرها من الإعدادات ← حسابي، أو يعيّنها عبد الله.

## المزامنة اليومية
بعد التحديثات: «إرسال» من جوال، و«استلام» على الآخر. الدمج آمن: لا تتكرر مكافأة ولا عملية.

## ملاحظات
- البيانات محفوظة في متصفح كل جوال. احذف بيانات Safari/Chrome فتضيع، فأرسل ملف مزامنة من وقت لآخر ليبقى نسخة لدى الطرف الآخر.
- عند تحديث التطبيق ارفع `index.html` و`sw.js` الجديدين فقط؛ البيانات لا تتأثر.
